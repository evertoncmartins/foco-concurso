# Envie aqui os bancos de questões do Sistema

No GitHub, use **Add file → Upload files**, envie o JSON diretamente nesta pasta e confirme o commit na branch `main`. A Vercel valida e publica os bancos automaticamente para todos os usuários.

| Arquivo | ID no JSON | Nome no JSON |
| --- | --- | --- |
| `lei-8112.json` | `lei-8112` | `Lei nº 8.112/1990` |
| `lei-8069.json` | `lei-8069` | `Lei nº 8.069/1990` |
| `lei-9394.json` | `lei-9394` | `Lei nº 9.394/1996` |

- Use `lei-NUMERO.json` e o mesmo `id`, sem pontos ou ano.
- Use o formato JSON do Foco e IDs estáveis para as questões.
- Para adicionar questões à mesma lei, substitua seu arquivo existente.
- Não edite nem envie `index.json`: o catálogo e as revisões são gerados automaticamente.
- Aguarde a implantação terminar. Arquivos inválidos impedem a atualização e preservam a versão publicada.
- Arquivos pessoais devem continuar no Drive ou ser importados pela plataforma.
